# AT&T Connectivity Marketplace — VTEX Architecture

Architecture proposal for the AT&T Connectivity Marketplace on VTEX: channels, core commerce, integration layer (mTLS), seller portal, Device Protection / Asurion, SSO, and Data Pipeline into Snowflake.

## Pages

- `index.html`: architecture diagram
- `raci.html`: condensed RACI v3 (AT&T, VTEX as prime, Clouda as subcontracted SI, third-party providers)

## Usage

Open `index.html` in a browser, or use the GitHub Pages site for this repository.

No build step is required.
